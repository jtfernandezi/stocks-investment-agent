# Stocks Investment Agent

AI-powered paper trading system for individual stocks. Builds on the ETF investment dashboard with 8 thematic niches, long/short positions, and a $60k fictional portfolio benchmarked against the S&P 500.

## Stack
- **Orchestration:** n8n (Railway)
- **Database:** Neon (PostgreSQL)
- **Trade execution:** Alpaca Paper Trading API
- **Dashboard:** Vercel (static HTML)
- **LLMs:** GPT-4o-mini (specialists) + GPT-5.1 (orchestrator)

## Niches (8)
1. Cybersecurity
2. Defense
3. Nuclear / Uranium
4. Copper / Critical Minerals
5. AI & Semiconductors
6. Cloud Hyperscalers
7. Oil & Gas
8. Data Centers & AI Infrastructure
